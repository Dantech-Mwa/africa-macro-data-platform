# 🌍 Africa Macro Data Platform

An end-to-end data engineering project analyzing African macroeconomic performance (2000–2025).

---

## 🚀 Project Overview

This project builds a full data pipeline:

- Data ingestion from World Bank API
- Data lake (raw → cleaned → curated)
- Spark-based transformations
- PostgreSQL data warehouse
- Power BI dashboard for visualization

---

## 🧱 Architecture

API → Data Lake → Spark ETL → PostgreSQL → Power BI

---

## 📊 Key Insights

- GDP comparison across Africa
- GDP per capita analysis
- Inflation vs growth relationship
- Africa Economic Strength Index (AESI)
- Forecasted GDP trends (2026–2030)

---

## 🛠 Tech Stack

- Python
- PySpark
- PostgreSQL
- Power BI
- Pandas
- SQL
